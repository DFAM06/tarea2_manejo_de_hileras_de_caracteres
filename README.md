- Debe investigar y mencionar qué es una hilera de caracteres, y algunos ejemplos.
Una hilera de caracteres es una secuencia de caracteres que forman un texto, algunos ejemplos son el formato String, un StringBuilder y un StringBuffer.

- Debe marcar la diferencia entre un carácter y una hilera.
La principal diferencia entre un carácter y una hilera es que las hileras son un conjunto de caracteres mientras que un carácter es solo una unidad.

- Investigue y mencione qué operaciones se pueden realizar con una hilera.
Algunas operaciones que se pueden realizar con una hilera es contar cuántos caracteres hay, localizar en qué índice está un carácter específico, dividir hileras, entre otros.
